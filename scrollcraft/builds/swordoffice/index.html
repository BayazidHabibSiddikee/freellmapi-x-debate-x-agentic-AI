Chapter 02

The most expensive line of code
is the one written from a
mislaid assumption.

AI coding agents fail most often not because they can't code, but because they're handed vague, single-perspective instructions. One prompt. One model's guess. Hours of cleanup when an unspoken constraint surfaces at review.

The fix isn't a better prompt. It's a better process.

Chapter 04

Rule 01

Hard tool gates, not prompt suggestions

Engineers hold code_task. Security and PM cannot write files. The boundary is enforced in the executor, not in the prompt.

Rule 02

One markdown file per persona

config/business/personas/*.md carries the full system prompt plus individual tool grants. Versionable, editable while services run, legible in any editor.

Rule 03

Judge artifact is machine-readable

Debates don't end in chat. They end in JSON: goal, decisions, self-contained subtasks with agent, cwd, and verifier. Validated before dispatch.

Researcher

download_books · youtube_transcript · study

Finds source material. Cites evidence. Distinguishes verified facts from speculation. Every claim has a source.

Engineer

Linus Wolf

code_task · run_tests · verify_output

Translates agreed designs into implementation details. Flags ambiguity. Prefers small verifiable steps.

Security

Ona the Sentinel

study · web_search · read_project_docs

Threat-models designs. Hunts injection surfaces, secrets leaks, auth flaws. Ranks findings by severity.

Analyst

June the Inspector

study · cross_team_search · publish_insight

Breaks problems down with data. Quantifies claims. Challenges hand-waving with numbers.

Reviewer

Kai the Builder

verify_output · run_tests

Inspects delivered work line-by-line. Correctness, edge cases, naming, test coverage. Rejects with actionable findings.

Each role lives in a persona file under config/business/personas/. Edit freely while the service runs.
