# Mobile App Project

Cross-platform mobile application development workspace.

## Tech Stack
- Flutter / React Native / Native
- Backend APIs as needed
- CI/CD pipeline

## Team
- **Engineer**: Build features, fix bugs, write tests
- **CTO**: Architecture decisions, tech stack choices
- **Researcher**: User research, competitive analysis

## Workflow
1. Define requirements in issues
2. Engineer implements features
3. CTO reviews architecture
4. Deploy to staging/production
